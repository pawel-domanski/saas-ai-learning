### What is Supervised Learning?

It's like learning with a tutor who provides the correct answer for each example:
- You show the system thousands of examples
- Each example has a label (correct answer)
- The system learns to recognize patterns connecting data with labels

### How Does It Work in Practice?

**Example: Teaching a System to Recognize Fruits**
1. Show a picture of an apple → label: "apple"
2. Show a picture of a banana → label: "banana"
3. Repeat with thousands of pictures of different fruits
4. System learns characteristic features (color, shape, texture)
5. When you show a new picture, the system predicts what fruit it is

### Two Main Tasks:

**🎯 Classification** - assigning to categories
- Is this email spam? (YES/NO)
- What's in the picture? (cat/dog/bird)
- What plant species is this? (rose/tulip/daisy)

**📈 Regression** - predicting numerical values
- What will be the house price? ($250,000)
- How many degrees tomorrow? (73°F)
- In how many minutes will the package arrive? (45 minutes)

### Where Do We Encounter This?
- Email spam filters
- Face recognition in phones
- Apps that translate text from images
- Systems diagnosing diseases from X-ray images
