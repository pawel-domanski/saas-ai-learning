### Origins (1956):
John McCarthy is the brilliant mind behind the term "artificial intelligence," a term he coined at the Dartmouth Conference. At first, AI was defined as the creation of machines that behave intelligently.

### Turing test:
Alan Turing came up with a simple test: if a person can't tell if they're talking to a human or a computer, then the computer is considered intelligent.

There are three main approaches we're exploring:
1. Turing test
The question we're exploring today is: can a machine convince a human that it is human?
2. Rational approach
I'm wondering if the machine is making the best decisions.
3. Cognitive approach
I'm curious: does the machine mimic human thought processes?

### Conclusion:
The definition of AI has evolved so much! It used to be just about imitating humans, but now it's all about achieving intelligent results in any way possible.
