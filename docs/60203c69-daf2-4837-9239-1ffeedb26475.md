## 📚 Lesson Content

### What is Reinforcement Learning?

It's like training a dog or playing a video game:
- Agent (program) takes actions in an environment
- Receives rewards for good decisions and penalties for bad ones
- Learns strategies that maximize rewards
- No instructions - only feedback

### Key Elements:

**🤖 Agent** - the "player" making decisions
**🌍 Environment** - the world where agent operates
**🎯 Actions** - possible agent actions
**🏆 Rewards** - points for good/bad actions
**📋 Policy** - strategy for choosing actions

### How Does It Work in Practice?

**Example: AI Learning to Play Pac-Man**
1. Agent (Pac-Man) sees the maze and ghosts
2. Can go up, down, left, or right
3. Gets points for eating a dot (+10)
4. Loses points for meeting a ghost (-100)
5. After thousands of games, learns to:
   - Collect dots
   - Avoid ghosts
   - Use power-ups strategically

### Difference from Other Methods:

**Supervised Learning:** "Here's the correct path through the maze"
**Unsupervised Learning:** "Find patterns in this maze"
**Reinforcement Learning:** "Try different paths, you get points for reaching the exit"

### Exploration vs Exploitation Problem

Agent must balance between:
- **Exploitation** - using proven strategies
- **Exploration** - trying new things

It's like choosing in a restaurant:
- Order your favorite dish (safe choice)
- Try something new (might be better!)
