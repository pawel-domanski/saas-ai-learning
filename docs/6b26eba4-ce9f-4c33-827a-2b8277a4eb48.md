**What are rule-based systems?**
These are programs that operate according to precisely defined instructions like "IF X happens, THEN do Y". They're like a very detailed cookbook - every step described exactly, with no room for improvisation.

**Example of a simple rule-based system (credit assessment):**
```
IF age < 18 years → reject application
IF income < $3000 → reject application  
IF unpaid credits = YES → reject application
IF all above = NO → approve application
```

**Examples from daily life:**
- **Call centers**: "Press 1 for..., press 2 for..."
- **Traditional thermostat**: "Below 68°F → turn on heating"
- **Simple chatbots**: "If question about hours → provide hours"
- **Tax calculators**: "Income X-Y → rate Z"

**Advantages (+):**
- Predictability - always the same reaction
- Transparency - you know why it made a decision
- Immediate action - no learning period needed
- Safety - lower risk of errors

**Disadvantages (-):**
- Rigidity - can't handle unforeseen situations
- Labor-intensive - you must predict all scenarios
- Limitations in complex problems
- No adaptation - doesn't learn from mistakes
