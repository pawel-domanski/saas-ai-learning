### Learning Process Step by Step

**1. Forward Propagation**
- Data enters through input layer
- Flows through hidden layers
- Prediction comes out

Like a child's first attempt: "Is this... a meow?"

**2. Calculating Error**
- Compare: What network said vs. What's the truth
- Calculate the "cost" of the mistake

Like telling the child: "No, that was a dog, not a cat!"

**3. Backpropagation**
- Error "travels back" through the network
- Each layer learns how much it messed up
- Weights are adjusted to reduce error

Like the child thinking: "Oh, so pointed ears = cat, droopy ears = dog"

**4. Repetition**
- Process repeated thousands/millions of times
- Network gets better with each iteration

### Analogy: Learning Basketball Shots

1. **First shot** - ball goes too far
2. **Error analysis** - "I threw too hard"
3. **Correction** - reduce throwing force
4. **Second shot** - ball goes too low
5. **Another correction** - increase angle
6. **After 100 shots** - hitting almost every time!

Neural network does exactly the same, just with numbers!

### Cost Function - Measure of Failure

Network needs a way to measure "how wrong it was":
- **Small numbers** = small errors = good!
- **Large numbers** = large errors = bad!

Examples of cost functions:
- **Mean squared error** - penalty grows with square of error
- **Cross entropy** - good for classification

### Learning Rate - Delicate Balance

**Too slow:**
- ✅ Stable learning
- ❌ Takes forever

**Too fast:**
- ✅ Quick progress
- ❌ Might "overshoot" good solution

Like learning to ride a bike:
- Too slow = you'll never move
- Too fast = you'll end up in the bushes

### Epochs and Batches

**Epoch** = one complete review of all training data

**Batch** = portion of data processed together

Like reading a book:
- Epoch = reading the whole book
- Batch = reading one chapter
- You learn after each chapter, not waiting until book's end

### Overfitting - When Network Memorizes

Problem: Network might memorize examples instead of learning general rules

Like a student who:
- ❌ Memorizes that problem 5 has answer "42"
- ✅ Understands how to solve this type of problem

Solutions:
- More diverse data
- Regularization techniques
- Early stopping of training
