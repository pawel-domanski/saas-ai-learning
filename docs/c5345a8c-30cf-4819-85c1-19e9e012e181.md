### Three Types of Layers

**1. Input Layer** - Company Reception
- Receives raw data from outside
- Each neuron handles one element (e.g., image pixel)
- Doesn't process, just passes forward

**2. Hidden Layers** - Processing Departments
- Where the real magic happens
- Each layer detects increasingly complex patterns
- Can be one or hundreds (hence "deep learning")

**3. Output Layer** - Executive Board Making Decisions
- Produces final result
- Number of neurons = number of possible answers

### Example: Network Recognizing Animals

**Structure:**
- Input: 100×100 pixels = 10,000 neurons
- Hidden: 3 layers with 128, 64, 32 neurons
- Output: 3 neurons (cat, dog, rabbit)

**How Information Flows:**

1. **Input layer** sees pixels
   - "Pixel[50,50] is brown"

2. **First hidden** detects simple shapes
   - "I see a vertical line"
   - "I see a round shape"

3. **Second hidden** combines shapes
   - "This might be an ear"
   - "This looks like an eye"

4. **Third hidden** recognizes body parts
   - "I see pointed ears"
   - "I see a fluffy tail"

5. **Output layer** makes decision
   - Cat: 85% confidence
   - Dog: 10% confidence
   - Rabbit: 5% confidence

### Connections - Information Highways

In a typical network, each neuron in a layer is connected to EVERY neuron in the next layer. It's like:
- Every employee in department A can email everyone in department B
- Some emails are more important (higher weights)
- Some are ignored (weights close to zero)

### Deep vs Shallow Networks

**Shallow networks** (1-2 hidden layers):
- ✅ Fast training
- ✅ Need less data
- ❌ Limited capabilities

**Deep networks** (many layers):
- ✅ Can learn very complex patterns
- ✅ Better results on difficult tasks
- ❌ Need huge amounts of data
- ❌ Long and expensive training

### Why Are Layers Important?

Each layer is another level of abstraction:
- Pixels → Edges → Shapes → Objects → Scenes

It's like building with LEGO blocks:
- First you connect individual blocks
- Then you build walls
- Finally, a whole castle emerges

Without layers, the network would have to go straight from pixels to "this is a cat" - impossible!
